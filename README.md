## 功能

- 无边框自定义标题栏：前进 / 后退 / 刷新 / 首页 / 在浏览器中打开
- 启动过渡动画与加载进度
- 网络异常提示与一键重试
- 视频全屏联动：播放器全屏时窗口同步全屏并隐藏标题栏
- 右键菜单：复制 / 粘贴 / 全选、复制链接、浏览器打开链接
- 快捷键：`Alt + ←/→` 前进后退、`Ctrl + R` / `F5` 刷新、`Ctrl + +/−/0` 缩放、`F11` 全屏
- 窗口位置、大小、最大化状态记忆
- 播放视频时阻止显示器休眠
- 单实例运行；登录状态本地持久化

## 下载

Windows x64 便携版见 [Releases](https://github.com/DownSG/mouguo-drama-desktop/releases)。

下载 `MouGuoDrama-1.0.0-portable.exe` 后直接双击运行，无需安装。首次启动会解压到临时目录，可能稍慢。

## 运行与构建

环境要求：Node.js 20+、Windows 10 1809+。

```bash
npm install
npm start          # 开发运行
npm run dist       # 打包 Windows x64 便携版，输出到 dist/
```

打包需要本机已安装支持 Windows 桌面开发的 Electron 依赖。构建产物为单文件便携版 exe，无需安装。

## 技术栈

- Electron 44
- 原生 HTML / CSS / JavaScript
- `<webview>` + 持久化 session

## 已知限制

- 不包含 Widevine CDM，若目标网站使用 DRM 加密视频则无法播放。
- 目标网站改版可能导致页面布局或功能异常。
- 不提供自动更新。
